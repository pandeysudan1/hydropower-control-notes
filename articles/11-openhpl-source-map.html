11 — OpenHPL Source Map Used in These Notes

This page records the OpenHPL components on which the analytical notes are based. It keeps the derivations traceable to the library rather than to a generic textbook model.

Library

Repository: OpenSimHub/OpenHPL. The current README describes OpenHPL as an open-source Modelica hydropower library with hydraulic components, turbine and generator models, power-system integration, controllers, and elastic-penstock models.

Hydraulic components

  • OpenHPL/Waterway/Reservoir.mo — reservoir level, hydrostatic outlet pressure, optional inflow and dynamic mass/momentum balance.
  • OpenHPL/Waterway/Pipe.mo — conduit model.
  • OpenHPL/Waterway/PenstockKP.mo — recommended elastic/compressible penstock with Kurganov–Petrova central-upwind discretization.
  • OpenHPL/Waterway/SurgeTank.mo — surge-tank storage and momentum behavior with several variants.
  • OpenHPL/Waterway/DraftTube.mo — draft-tube hydraulic model.

Electromechanical components

  • OpenHPL/ElectroMech/Turbines/Francis.mo — detailed Francis turbine with guide-vane geometry, Euler power terms and losses.
  • OpenHPL/ElectroMech/Turbines/Turbine.mo — simpler turbine representation.
  • OpenHPL/ElectroMech/Generators/SimpleGen.mo — rotational-energy generator model.
  • OpenHPL/ElectroMech/Generators/SynchGen.mo — synchronous generator model.
  • OpenHPL/ElectroMech/PowerSystem — grid/power-system coupling, including OpenIPSL-based integration.

Control

  • OpenHPL/Controllers/Governor.mo — frequency and power-reference governor with permanent droop, transient droop, pilot servo, main servo, rate limiting and gate-position limiting.

Important modeling rule

Whenever a reduced equation is shown in these notes, it should be understood as one of three things: (1) an equation directly represented in OpenHPL, (2) a compact analytical rewriting of the same physical balance, or (3) a reduced model derived around an operating point. The reduced FCR transfer functions are not claimed to be the native state equations of OpenHPL.
