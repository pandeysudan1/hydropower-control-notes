Homotopy and DAE Events

This note explains what happens mathematically when a nonlinear DAE experiences a controller event, why consistent algebraic states must be recomputed, and how homotopy can help solve the resulting nonlinear equations.

1. Nonlinear DAE before an event

Consider

$$\dot x=f(x,z,u),$$ $$0=g(x,z,u).$$

Immediately before an event at $t=t_e$, the state satisfies

$$g(x^-,z^-,u^-)=0.$$

2. Controller update

Suppose the controller changes the input discontinuously:

$$u^-\rightarrow u^+.$$

For physical differential states without an impulsive reset,

$$x^+=x^-.$$

However, the old algebraic state need not remain valid because generally

$$g(x^-,z^-,u^+)\neq0.$$

3. Consistent post-event algebraic state

The solver must determine $z^+$ such that

$$\boxed{g(x^-,z^+,u^+)=0}.$$

This is the algebraic reinitialization problem.

4. Why the problem may be difficult

The equation

$$g(z)=0$$

can be nonlinear, poorly scaled, or close to singular. Newton iteration gives

$$z_{n+1}=z_n-\left[\frac{\partial g}{\partial z}(z_n)\right]^{-1}g(z_n).$$

Convergence can fail if the initial guess is poor or the Jacobian is nearly singular.

5. Homotopy construction

Let $g_0(z)=0$ be an easier problem with known solution $z_0$. Define

$$\boxed{H(z,\lambda)=(1-\lambda)g_0(z)+\lambda g(z)}$$

for

$$0\le\lambda\le1.$$

At $\lambda=0$,

$$H(z,0)=g_0(z),$$

and at $\lambda=1$,

$$H(z,1)=g(z).$$

6. Continuation path

We seek a curve $z(\lambda)$ satisfying

$$H(z(\lambda),\lambda)=0.$$

Differentiating with respect to $\lambda$ gives

$$H_z\frac{dz}{d\lambda}+H_\lambda=0.$$

If $H_z$ is nonsingular,

$$\boxed{\frac{dz}{d\lambda}=-H_z^{-1}H_\lambda}.$$

This is the tangent equation for the continuation path.

7. Numerical predictor-corrector idea

With continuation step $\Delta\lambda$, a predictor is

$$z_{k+1}^{pred}=z_k+\frac{dz}{d\lambda}\Delta\lambda.$$

A Newton corrector then solves

$$H(z,\lambda_{k+1})=0.$$

Repeating this process gradually moves from the easy problem to the desired nonlinear problem.

8. Physical time is not homotopy time

The most important distinction is

$$\boxed{\frac{dx}{dt}\neq\frac{dz}{d\lambda}}.$$

The variable $t$ is physical time. The variable $\lambda$ is a numerical continuation coordinate. A homotopy trajectory is not a physical transient of the hydropower plant.

9. Three mathematical coordinates

In a hybrid frequency-control simulation we may have

$$t\in\mathbb R_{\ge0}$$

for physical time,

$$k\in\mathbb Z_{\ge0}$$

for controller-update index, and

$$\lambda\in[0,1]$$

for numerical continuation. Therefore

$$\boxed{t\neq k\neq\lambda}.$$

10. Event sequence

A clean event procedure is:

$$x^- ,z^- ,u^-\quad\longrightarrow\quad u^+=\Phi(x^-,z^-,u^-),$$

then hold

$$x^+=x^-,$$

and solve

$$g(x^+,z^+,u^+)=0.$$

Only after obtaining a consistent $(x^+,z^+)$ does continuous integration restart.

11. Differential-state resets

If a true physical reset exists, then

$$x^+=R(x^-,z^-,u^-).$$

The consistency problem becomes

$$g(x^+,z^+,u^+)=0.$$

For ordinary governor set-point changes, the physical hydraulic and mechanical states are usually continuous, while algebraic variables may jump.

12. Index-1 DAE interpretation

For an index-1 semi-explicit DAE

$$\dot x=f(x,z,u),$$ $$0=g(x,z,u),$$

regularity requires

$$\det(g_z)\neq0.$$

Then locally

$$z=\psi(x,u),$$

and event reinitialization is well posed near the operating point.

13. Near-singular operation

If

$$\det(g_z)\approx0,$$

small changes in input can produce large changes in algebraic variables. This may indicate numerical difficulty, a physical limit, or proximity to a bifurcation such as voltage collapse or another constraint singularity.

14. Homotopy around a controller event

For a jump from $u^-$ to $u^+$, a useful continuation is

$$u(\lambda)=(1-\lambda)u^-+\lambda u^+.$$

Then solve

$$\boxed{g(x^-,z(\lambda),u(\lambda))=0}.$$

At $\lambda=0$, $z(0)=z^-$. At $\lambda=1$, the solution is the consistent post-event state $z^+$.

15. Differentiating the event homotopy

Define

$$H(z,\lambda)=g(x^-,z,u(\lambda)).$$

Then

$$H_z\frac{dz}{d\lambda}+H_u\frac{du}{d\lambda}=0,$$

so

$$\boxed{\frac{dz}{d\lambda}=-g_z^{-1}g_u\frac{du}{d\lambda}}.$$

This equation has a clear interpretation: it gives the sensitivity of algebraic states to a gradual numerical continuation of the controller input.

16. Relation to initialization

At the beginning of a simulation, the same consistency problem appears:

$$f(x^\star,z^\star,u^\star)=0,$$ $$g(x^\star,z^\star,u^\star)=0.$$

Homotopy can therefore be useful both for initial operating-point solution and for difficult event reinitialization.

17. Synchronization and homotopy are different issues

Synchronous programming determines when and in what order controller events are executed. Homotopy determines how a difficult nonlinear algebraic solve may be continued from an easier one. There is no general mathematical identity requiring synchronous programming merely because a solver uses homotopy.

18. Compact hybrid DAE formulation

The complete structure can be summarized as

$$\begin{cases}F(\dot x,x,z,q)=0,&t\notin\mathcal T,\\q^+=\Phi(x^-,z^-,q^-),&t\in\mathcal T,\\x^+=R(x^-,z^-,q^-),&t\in\mathcal T,\\0=g(x^+,z^+,q^+),&t\in\mathcal T.\end{cases}$$

If the last equation is hard to solve directly, introduce a continuation parameter $\lambda$.

19. Main conclusion

Physical time $t$, controller index $k$, and homotopy parameter $\lambda$ describe different mathematical processes. Homotopy is a numerical continuation device used to obtain a consistent nonlinear solution; it should not be interpreted as the physical evolution of the hydropower plant.
