Primary and Secondary Frequency Control

This note separates primary frequency response from secondary control and shows how both can be written as one hierarchical dynamical system.

1. Power imbalance and frequency

For an aggregated synchronous area,

$$M\Delta\dot\omega=\Delta P_m-\Delta P_L-D\Delta\omega.$$

A sudden increase in demand gives $\Delta P_L>0$, so initially

$$\Delta\dot\omega(0^+)\approx-\frac{\Delta P_L}{M}.$$

Thus inertia determines the initial rate of frequency change.

2. Primary frequency control

Droop response is

$$\Delta P_{\rm FCR}=-\frac{1}{R}\Delta\omega.$$

With governor and turbine dynamics represented by $G_g(s)$ and $G_h(s)$,

$$\Delta P_m(s)=-G_h(s)G_g(s)\frac{1}{R}\Delta\Omega(s).$$

Primary control acts quickly and arrests frequency decline.

3. Primary-control equilibrium

At steady state,

$$0=\Delta P_m-\Delta P_L-D\Delta\omega.$$

If the static primary gain is $K_p^{\rm FCR}$, then

$$\Delta P_m=-K_p^{\rm FCR}\Delta\omega,$$

giving

$$\boxed{\Delta\omega_{\rm ss}=-\frac{\Delta P_L}{D+K_p^{\rm FCR}}}.$$

Frequency is stabilized, but generally not restored exactly to nominal.

4. Why secondary control is needed

Secondary control changes the reference operating point so that primary reserves can be released and the long-term frequency error can be removed.

For one control area, a simple integral secondary controller is

$$\dot\eta=-K_I\Delta\omega,$$

with reference correction

$$\Delta P_{\rm ref}=\eta.$$

At equilibrium, $\dot\eta=0$ implies

$$\Delta\omega=0.$$

5. Area control error

For interconnected areas, secondary control commonly uses the area-control error

$$\boxed{ACE=\Delta P_{\rm tie}+B\Delta f},$$

where $B$ is frequency-bias gain. A PI-type AGC can be written

$$\dot\eta=-K_I ACE,$$

and

$$u_{\rm AGC}=-K_P ACE+\eta.$$

6. Hierarchical reference construction

The governor reference may contain the scheduled operating point, primary droop, and secondary correction:

$$\boxed{P_{\rm ref}=P_0-\frac{1}{R}\Delta\omega+u_{\rm AGC}}.$$

This equation makes the hierarchy explicit: the local droop term responds immediately to frequency, while AGC slowly moves the operating point.

7. Multi-machine participation factors

If total AGC command is $u_A$, generator $i$ may receive

$$u_i=\alpha_i u_A,$$

with

$$\alpha_i\ge0,\qquad\sum_{i=1}^{N}\alpha_i=1.$$

The participation factors distribute secondary regulation according to reserve, economics, ramping ability, or operator policy.

8. Closed-loop state model

Let the plant state be $x$, governor state $x_g$, and AGC integrator $\eta$. Then a compact continuous model is

$$\dot x=f(x,z,y_g,d),$$ $$0=g(x,z,y_g,d),$$ $$\dot x_g=f_g(x_g,\Delta\omega,P_{\rm ref}),$$ $$\dot\eta=-K_I ACE.$$

Collecting states into

$$X=\begin{bmatrix}x^T&x_g^T&\eta\end{bmatrix}^T,$$

gives

$$\dot X=\mathcal F(X,Z,d),\qquad0=\mathcal G(X,Z,d).$$

9. Linearized two-layer control

A linear model may be written

$$\Delta\dot x=A\Delta x+B_g\Delta u_g+B_d\Delta d,$$ $$\Delta\dot\eta=-K_I(C_{ACE}\Delta x),$$

with

$$\Delta u_g=-K_R C_\omega\Delta x+\alpha\Delta\eta.$$

Substitution gives the augmented system

$$\boxed{\frac{d}{dt}\begin{bmatrix}\Delta x\\\Delta\eta\end{bmatrix}=\begin{bmatrix}A-B_gK_RC_\omega&B_g\alpha\\-K_IC_{ACE}&0\end{bmatrix}\begin{bmatrix}\Delta x\\\Delta\eta\end{bmatrix}+\begin{bmatrix}B_d\\0\end{bmatrix}\Delta d}.$$

11. Reserve interpretation

Primary reserve changes power according to frequency:

$$\Delta P_{\rm primary}\propto-\Delta f.$$

Secondary reserve changes power according to accumulated system imbalance:

$$\Delta P_{\rm secondary}\propto-\int ACE\,dt.$$

Therefore primary control is decentralized feedback, while secondary control is a slower supervisory correction.

12. Saturation and anti-windup

If

$$P_{\min}\le P_{\rm ref}\le P_{\max},$$

the AGC integrator can wind up when saturation is active. One correction is

$$\dot\eta=-K_IACE+K_{aw}(u_{sat}-u).$$

This is important for hydropower units near guide-vane, discharge, or power limits.

13. Main conclusion

Primary control arrests the disturbance and shares it through droop. Secondary control changes the reference so that frequency and interchange errors are restored. Both can be represented continuously, discretely, or as a hybrid system; the control purpose is separate from the software execution model.
