12 — Continuous vs Sampled AGC: a Numerical Experiment

This note turns the earlier solver discussion into a reproducible toy experiment. The aim is not to prove that AGC must be digital. The aim is to show why hard constraints can make a continuous closed-loop model numerically harder, and why a sampled controller can partition the problem more cleanly.

1. Plant and controller

We use a reduced single-area hydropower model:

$$M\dot{\Delta f}=K_t y_g-\Delta P_L-D\Delta f,$$

with a pilot servo

$$T_p\dot v+v=e,$$

and governor/AGC error

$$e=-\Delta f-R(y_g-y_{g,0})+\xi_A,$$

where the AGC integrator satisfies

$$\dot\xi_A=-K_I B\Delta f.$$

2. Continuous constrained gate

The unconstrained main servo would be

$$\dot y_g=\frac{v}{T_g}.$$

Realistic constraints impose

$$y_{min}\le y_g\le y_{max},$$ $$-r_c\le\dot y_g\le r_o.$$

The gate law therefore becomes piecewise:

$$\dot y_g=\begin{cases}0,&y_g=y_{max},\;v>0,\\0,&y_g=y_{min},\;v<0,\\r_o,&v/T_g>r_o,\\-r_c,&v/T_g<-r_c,\\v/T_g,&\text{otherwise}.\end{cases}$$

The continuous solver must detect changes in the active branch while also integrating the other states.

3. Why discretization matters

For an implicit time step, a method such as backward Euler produces

$$x_{n+1}-x_n-hf(x_{n+1})=0.$$

This is a nonlinear algebraic problem at every step. If Newton iterations cross a limiter surface, the effective vector field and Jacobian change. Adaptive solvers may respond by reducing the step, rejecting the step, or locating an event more accurately.

This is the direct relation between controller nonsmoothness and solver discretization: the original continuous model is converted into a sequence of nonlinear algebraic solves, and the active constraint set can change inside those solves.

4. Sampled controller

In the sampled alternative, the controller runs only at

$$t_k=kT_s.$$

At each tick we compute a desired increment and explicitly apply the rate and position constraints:

$$\Delta y_k=\operatorname{sat}(y_{cmd,k}-y_{g,k},-r_cT_s,r_oT_s),$$ $$y_{g,k+1}=\operatorname{clip}(y_{g,k}+\Delta y_k,y_{min},y_{max}).$$

Between ticks,

$$y_g(t)=y_{g,k},\qquad t_k\le tThe plant therefore evolves continuously with a known held input between controller events.

5. Expected numerical difference

The continuous version may show more root-finding work around gate limits, more rejected steps, or smaller adaptive steps. The sampled version moves most limiter logic to explicit event times. This does not make the physics more correct; it changes the numerical partitioning.

6. Homotopy is a separate mechanism

After an event, a DAE may need a new algebraically consistent state:

$$g(x^-,z^+,u^+)=0.$$

If that nonlinear solve is difficult, a continuation problem can help:

$$H(z,\lambda)=(1-\lambda)g_{old}(z)+\lambda g_{new}(z)=0.$$

The continuation parameter is numerical:

$$\boxed{\lambda\neq t\neq kT_s}.$$

Time discretization, sampled-control timing, and homotopy are three distinct mechanisms.

7. What to measure

A useful comparison should record:

  • frequency nadir and settling time,
  • guide-vane trajectory,
  • AGC integrator trajectory,
  • accepted and rejected solver steps,
  • nonlinear iterations and event count,
  • minimum adaptive time step near limiter activation.

8. Julia experiment

The companion script is available in examples/continuous_vs_sampled_agc.jl. It uses DifferentialEquations.jl and compares the two controller formulations under the same load step and model parameters.

The main hypothesis to test is:

$$\boxed{\text{hard continuous constraints can increase numerical difficulty even when the underlying AGC law is continuous}.}$$

The sampled formulation is useful when the control implementation itself is digital, and it can also be a numerically convenient way to separate supervisory logic from the nonlinear physical plant.
