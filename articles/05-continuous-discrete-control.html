Continuous Physics and Discrete Control

This note separates continuous physical time from sampled controller execution. The purpose is to clarify the mathematics behind synchronous and asynchronous control implementations.

1. Continuous physical plant

The nonlinear hydropower plant is represented by

$$\dot x=f(x,z,u),$$ $$0=g(x,z,u).$$

The independent variable is physical time

$$t\in\mathbb R_{\ge0}.$$

2. Sampled controller

A digital controller executes at times

$$t_k=kT_s.$$

Measurements are sampled as

$$y_k=y(t_k),$$

and the controller update is

$$q_{k+1}=\Phi(q_k,y_k).$$

The command may be

$$u_k=\Psi(q_k,y_k).$$

3. Zero-order hold

Between controller events, the digital command is commonly held constant:

$$u(t)=u_k,\qquad t_k\le tThe continuous DAE therefore evolves as

$$\dot x=f(x,z,u_k),$$ $$0=g(x,z,u_k),$$

until the next discrete event.

4. Hybrid-system representation

The combined system can be written as

$$\begin{cases}\dot x=f(x,z,q),\\0=g(x,z,q),&t\notin\mathcal T,\\q^+=\Phi(x,z,q),&t\in\mathcal T,\end{cases}$$

where $\mathcal T$ is the set of controller-event times.

5. Continuous PI versus digital PI

A continuous PI controller is

$$\dot\xi=e(t),$$ $$u(t)=K_pe(t)+K_i\xi(t).$$

Using forward Euler with sample time $T_s$ gives

$$\xi_{k+1}=\xi_k+T_se_k,$$ $$u_k=K_pe_k+K_i\xi_k.$$

The two models approach each other as $T_s$ becomes small relative to the dominant plant timescales.

6. Synchronous execution

For a synchronous sampled controller, update times are predetermined:

$$t_k=kT_s.$$

All controller blocks assigned to that clock evaluate a consistent sampled state, for example

$$q_{k+1}=\Phi(x(t_k^-),q_k).$$

This gives a deterministic event map.

7. Asynchronous execution

An asynchronous controller may update at irregular times

$$t_{k+1}=t_k+T_s+\epsilon_k,$$

where $\epsilon_k$ represents jitter, communication delay, or event-driven execution. The mathematics remains valid; only the event set changes:

$$\mathcal T=\{t_0,t_1,t_2,\dots\}.$$

8. Multiple controller clocks

Primary and secondary control may operate at different rates:

$$t_k^{(p)}=kT_p,$$ $$t_j^{(s)}=jT_s,$$

with typically

$$T_p\ll T_s.$$

The complete event set is

$$\mathcal T=\mathcal T_p\cup\mathcal T_s.$$

This is a multi-rate hybrid system.

9. Event ordering

If two discrete updates occur at the same physical time, ordering can matter. Let

$$q_A^+=\Phi_A(x,q_A,q_B),$$

and

$$q_B^+=\Phi_B(x,q_A,q_B).$$

If block A uses the updated value from B, while B uses the old value from A, then the result depends on execution order. In general,

$$\Phi_A\circ\Phi_B\neq\Phi_B\circ\Phi_A.$$

This is a non-commutativity problem, not a property of hydropower physics itself.

10. Simultaneous event map

A mathematically clean synchronous formulation is

$$\begin{bmatrix}q_A^+\\q_B^+\end{bmatrix}=\Phi\left(x^-,q_A^-,q_B^-\right).$$

Both updates use the same pre-event state. This removes ambiguity.

11. Measurement delay

If a measured signal arrives after delay $\tau$,

$$y_k=y(t_k-\tau).$$

A droop controller becomes

$$u_k=-\frac{1}{R}\Delta\omega(t_k-\tau).$$

Delay changes phase and can reduce stability margins even though the underlying controller law is unchanged.

12. Exact sampled-data viewpoint

For a linear continuous plant

$$\dot x=Ax+Bu,$$

with zero-order hold, exact discretization gives

$$x_{k+1}=A_dx_k+B_du_k,$$

where

$$A_d=e^{AT_s},$$

and

$$B_d=\int_0^{T_s}e^{A\tau}B\,d\tau.$$

This is the rigorous bridge between continuous dynamics and sampled control.

13. Stability in discrete time

For

$$x_{k+1}=A_{cl}x_k,$$

asymptotic stability requires

$$\boxed{|\lambda_i(A_{cl})|<1\quad\forall i}.$$

This differs from continuous-time stability, where eigenvalues must lie in the open left half-plane.

14. Sampling-time requirement

There is no universal sampling period, but the controller should sample substantially faster than the dynamics it must regulate. If $\omega_b$ is a relevant closed-loop bandwidth, one practical design condition is

$$\omega_s=\frac{2\pi}{T_s}\gg\omega_b.$$

The exact ratio is a design choice, not a physical law.

15. Continuous FCR and sampled AGC

A useful practical architecture is

$$\text{continuous or fast droop/FCR}+\text{slower sampled AGC}.$$

For example,

$$u_{FCR}(t)=-\frac{1}{R}\Delta\omega(t),$$

while

$$\eta_{k+1}=\eta_k-K_IT_sACE_k.$$
